## Fixed workflow

Use only the adjacent Windows supervisor with one explicit phase:

1. `--freeze`: pins all local sources/tests/README/protocol, ADR141, capture
   constructors, model dependencies, sealed labels, and exact reused V3 inputs.
2. External reviewed capture-v4 wrapper collects all new80 TRAIN once, separately.
3. `--encode-expansion`: three encodes per available row (title once + two bodies).
4. `--fit-calibrate`: all old48 TRAIN + new80 TRAIN, whole old48 CAL; six declared
   view/weight candidates, lambda .1. No consumed old32 final file is opened.
5. External wrapper may collect new32 final only after exclusive persisted receipt.
6. `--encode-test`, then `--test`: title+selected body only (64calls if32complete),
   one selected root model/cut, all32 final rows;
   missing selected-view inputs unresolved, no replacement or view fallback.
7. `node verify.js --verify`: stored bytes and saved-score/path arithmetic only.

Every phase consumes an exclusive marker and wx outputs, including failures.
No automatic replay, alternate hidden phase, capture, network or data replacement.
Default runner, verifier and supervisor are inert. Initial buffers are retained
per phase; those same bytes are hashed and parsed, then fresh-read before output.
This is a local identity fence, not hostile-filesystem/native attestation.
