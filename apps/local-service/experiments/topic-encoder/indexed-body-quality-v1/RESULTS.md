# Fixed indexed BODY policy quality result

The installed BODY representation with its fixed indexed supported-merge policy
substantially increases false discussion exposure on the two reused fictional
challenge cohorts. **Do not activate this policy based on these results.** No
cutoff, artifact, grouping rule or input was changed after measurement.

The descriptor was generated and saved before the single measurement run:
`1319dc9c64666a150a29ecbe3808dc83ceb06503d75349189c6edb2330ae7bd3`.
See `freeze.json` for all source/cohort hashes and `aggregate.json` for complete
content-free counts, diagnostics and policy differences. Installed BODY manifest:
`4ee584e21acc180ca721dc520781f7abdf0b770d96ef28e32ac2b3bb6dc42eeb`.

All three representations use packaged E5 body-prefix input. Raw and diagonal
use `alternate-indexed-independent-evidence/v2` (seed/support 0.94, weakest cross
0.90). BODY uses `alternate-indexed-body-metric/v1` with seed/support/weakest
cross all `0.3622392629925627`. Both use crowded-neighbor count 3. Representation
and admission therefore both differ; this is not an isolated representation
comparison and is not the prior strongest-edge complete-link research policy.

Every planner/cohort run completed. There were no capacity failures, incomplete
retrievals, partial partitions or runtime errors. Partitions covered all expected
Sources exactly once. Exhaustion still throws without returning a partial result;
the separately executed restricted regression suite covered that path and the
whole-plan deadline, including transformation. No fitting, calibration, model
download, provider call, SQLite work or live activation occurred in this harness.

The reused shared296 translated-news corpus contains no viewpoint gold labels.
Its opposing-viewpoint denominator is zero, so it cannot establish viewpoint
coverage. The authored C108 challenge has 270 same-event opposing-viewpoint
pairs: Raw joins 21, diagonal 23, BODY 218. The spent v6 challenge has 120:
Raw joins 2, diagonal 7, BODY 120. That increased coverage is accompanied by
large false joins, rather than validated separation of adjacent developments.

Same-family different-event pairs are only an adjacent-story proxy. On C108,
Raw joins 18/648 such pairs, diagonal 19/648 and BODY 204/648. On v6, Raw and
diagonal each join 0/450, BODY joins 125/450. These synthetic labels implement a
narrow principal-development target; they do not settle whether every real
successive stage should receive a separate Topic. Synthetic viewpoints are not
independent publisher perspectives or fluent-human-reviewed prose.

Relative to diagonal, BODY adds 999 correct and 2 false grouped pairs on
shared296, 195 correct and 221 false on C108, and 113 correct and 125 false on
v6. It removes no previously grouped pair on any of these cohorts. The favorable
translated-news coverage cannot cancel the severe challenge-cohort false exposure.

These cohorts were already measured in prior research and are explicitly reused;
none is a fresh independent holdout. Input is a corpus-body surrogate, not actual
Chrome capture. No real-page error rate, calibrated semantic identity, rights,
scale, distribution or release conclusion follows. Article text, Source IDs,
event labels, vectors and weights were not saved by this harness or added to Git.
