# Owner-local diagonal adapter installation

This opt-in installer reruns the frozen 475-record GlobeSumm fit from the reviewed private corpus and writes only 384 fitted parameters plus identity/digest metadata. The parser reads all 4,687 records into memory to validate the frozen split, but only the 475 fit records are embedded or used for training. It does not embed or evaluate validation/test records, persist text/vectors, call a network service, or activate Topic routing.

After independent review, invoke `node apps/local-service/experiments/topic-encoder/local-adapter-install-v1/run.js --private-dir ABSOLUTE_PRIVATE_DIRECTORY --input ABSOLUTE_PRIVATE_CORPUS_FILE --output ABSOLUTE_REPOSITORY_PATH/apps/local-service/data/diagonal-adapter-v1.json`. The output path must be exactly the named Git-ignored `data/` file and must not already exist. The installer checks the fixed private corpus digest and size, the pinned reviewed digest manifest and its listed dependencies, exact 749/475/274 train split, packaged E5 model identity, and 40-step fit before exclusive file creation. The installer script itself is not pinned by that reviewed manifest. It prints only metadata and hashes. No private run is performed by adding this code.

The output check runs again immediately before exclusive creation. Before writing any parameters, the installer checks that the opened file and parent still resolve to the intended path. A failed post-open check can leave an empty file. This is intended for an owner-controlled local workspace; it is not race-proof against a same-account process swapping directories. A release-grade Windows implementation needs a handle-based path and reparse-point check.

The local adapter file is an owner-local artifact. Keep it out of Git and do not distribute it without a separate rights decision. The strict domain loader verifies its manifest and applies its bounded diagonal scale to an existing normalized browser E5 vector without changing the input vector. It is not wired into routing by this module.
