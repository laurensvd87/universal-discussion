## EXACT proposed practical composition

Outer policy `ridge1-qualified-complete-link/v1` is NEW pure research code.
It reuses unchanged `planIndexedAlternateTopics` and the unchanged negative-role
qualifier from `guarded-body-topic-planner`, NOT that hardcoded BODY planner.

1. Validate provisional learned Sources, extractor/model IDs and finite unit
   norms. Manual-confirmed/nonlearned Sources never enter the proposal or its
   transforms; canonical IDs/links remain untouched. Reject proxies/getters.
2. Apply the existing conservative known-negative URL/title qualifier FIRST.
   Each negative Source is a singleton and cannot seed/witness any join. Unknown
   or missing contexts and unfamiliar scripts remain eligible; no positive
   title overlap, entity identity, brand blacklist or language veto is required.
3. Transform only eligible raw vectors transiently, guard norm/overflow locally,
   then feed them to the unchanged indexed coarse planner. It collapses exact
   vector equality for independent evidence, then expands ALL original IDs.
4. Refine EACH expanded coarse block using full-precision strongest represented
   edges, Source-ID ties and a full-cross complete-link check at its fixed floor.
   No cross-block admissions, raw E5 veto, fixed nearest count or membership cap.
   Since seed/support/weak share a floor, coarse admissions already require
   all-cross qualification mathematically. Its seed/mean merge ordering still
   differs from the earlier global strongest-edge research graph; never
   substitute those earlier results for this exact composition.

The current INDEXED admission validator accepts only the legacy internal name
`alternate-indexed-body-metric/v1`. Its use is an implementation seam, not a
claim that Ridge1 is the prior BODY whitening metric. Output explicitly reports
the truthful OUTER policy, actual representation/floor and inner policy name.
Any future integration needs a separately reviewed production version seam.

All phases share100,000,000 work units and10-second whole-plan deadline.
Coordinate copies, transform boundaries, pair scoring, full-cross checks and
edge sorting debit/check the shared guard. FIFO pair cache is bounded65,536;
edge/sort allocation is conservatively charged192 bytes per edge against8MiB.
Failure/exhaustion yields no partial partition or pruning. No budget is treated
as semantic identity, and none is relaxed after measurement. IDs are all retained
in a complete proposal or no proposal is returned. These are computational work/
memory limits, not maximum pages per Topic.

## Execution and privacy

`--freeze` only reads/hashes/selects inputs and emits a content-free descriptor:
no model inference, fit or quality. Lead reviews README/run/planner and freeze.
`--measure --freeze-hash HASH` must reproduce it, perform475 paired refit,
verify the exact learned-parameter hash, then embed the new real/v7 inputs with
E5 ONLY. One ONNX session at a time,64-report work batches (not group limits).
The closed helper is never changed; a local norm guard rejects overflow before
normalization. Private input paths/parents are regular/non-symlink, realpath/scope
checked and byte/hash pinned. External network/subprocess capabilities are denied
before private input. Failures print only a fixed code, not raw stacks/prose.

Prose, vectors, targets, means and matrix remain RAM-only. ONLY content-free
freeze/aggregate/results may be saved in this directory. No weights saved here;
an eventual ignored-weight installer is separate and requires review. Owner
permission to fit does not establish corpus/model redistribution rights or a
release gate. News labels are not independently reviewed app-Topic/publisher/
viewpoint gold. Calibration precision is not a confidence bound.

The eight focused and ten independent trust tests are part of the frozen
sources. They cover qualified duplicates, all-coordinate/no-raw-veto checks,
manual invariants, ordering, finite norm guards, corrupt screening counts,
whole-plan work/deadline boundaries, later-block abort and output isolation.
