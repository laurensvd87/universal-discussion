## Fixed read and admission boundaries

plus115 installed Playwright tree entries (173 alias keys), own13 files and the
reused pure/scorer/encoder dependencies. Node and Python maps are tested equal.
No path is followed from JSON. Selected artifact FILE hashes stay distinct from
the scorer's property-order JSON.stringify model digest; neither authenticates
an arbitrary already-loaded module. Actual byte buffers are privately retained
and parsed from those same bytes; fresh rechecks precede delivery/publication.

Public ledger reads forbid input and vector packets. A private metadata handle
requires all eight four-row capture results, their exact source/profile/reuse
bindings, prior-chain byte hashes, finite resources and successful own-tree drain.
The explicit supervised admission phase compiles the actual selected artifacts

private handle requires its actual saved receipt AND successful supervisor, bound
to receipt bytes, evaluator freeze FILE SHA, source map, resources and cleanup.
Missing, failed or drifted proof grants no packet reader or encoder call.

Each encode batch reads only through that handle. Both unmodified field contracts
are validated for every row BEFORE encoder initialization/first call. Empty title,
unsupported text or capture refusal remains unavailable; no alternate builder,
trimming, title-only rescue, equal-input reuse or retry. The existing packaged E5
loader hashes installed assets and uses one-thread local ORT under the offline
guard. Its model/embedding-contract/asset-manifest encoder hash must match the
original selected artifact. At most8 calls/batch and64 overall are permitted.

All eight encoding receipts AND successful supervisors are checked before private

Classification uses the actual private scorer, never supplied paths or scores.

## Stored audit and scope

    node verify.js --verify-stored

The stored verifier performs hash/arithmetic checks without importing an encoder,
model compiler or classifier. It checks actual admission/encoding proofs, packet
byte links, full32-per-browser outcomes, conditional availability, per-root/
language/host counts, reason ledger, work and timing sums. It does NOT re-execute
classification or prove a saved prediction was honestly produced numerically.
Reports explicitly retain reobservation and statisticalIndependenceClaim:false;
there are32 distinct article groups, not a fresh untouched cohort or64 trials.

The fixed feasibility gate remains >=24 accepted, zero wrong accepted and at least
one accepted per root over ALL32 rows. No post-score dropping, retuning or URL
replacement. Passing it would not establish crawler/static transfer, child/OOD
quality, population precision, ordinary dynamic-browser behavior or a production
cutover. Classifier time excludes capture/E5/queue/DB/UI time. Existing canonical
route IDs, posts, memberships, native/account/write/AI proofs are untouched.

Pure tests use invented strings, metadata and axes; CODE/package path inspection
does not open retained inputs or actual selected artifacts. Review and an explicit
root-written freeze remain mandatory before any actual phase.
