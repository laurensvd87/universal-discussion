# Multilingual balanced fictional event corpus v1

This directory contains an original synthetic corpus for controlled research. It has 12 fictional event families, each with two distinct developments involving the same actor or institution. Every development has two short article records in each of English, German, Dutch, French, and Spanish: 240 records total. The supportive and questioning record for each development-language pair uses a different event-core wording with the same central event and distinguishing facts.

Viewpoint assignment is counterbalanced: every language contains 24 supportive and 24 questioning records, and each development-language pair has one of each. Family assignment is indivisible: eight families are in `train.jsonl`, two in `validation.jsonl`, and two in `test.jsonl` (160/40/40 records). Test is sealed for downstream evaluation; this package only checks corpus structure and does not score matching.

All events, institutions, places, quantities, and prose are fictional and were generated for this corpus with GPT-6 Luna assistance. Event descriptions, titles, and viewpoints are written in each declared language, but have not had independent fluent review. The paired event-core paraphrases are generated by deterministic language-specific substitutions and sentence reordering. No real page text, external source, provider call by the corpus generator, or model weights are used. `build.js` deterministically regenerates the JSONL files. Run `node apps/local-service/experiments/topic-encoder/multilingual-balanced-v1/integrity.test.js` to check counts, family isolation, normalized text uniqueness, per-language balance, pair completeness, distinct developments, absence of the original English core strings from non-English records, and non-prefix/different-wording event cores in each pair.

Limitations: this is a small synthetic set, not a representative multilingual benchmark. The questioning cores are generated from curated language-specific lexical substitutions and sentence reordering; where a substitution rule does not match, a localized framing clause is used. They create wording variation but are not fully independent human-authored editorial accounts. A fluent human reviewer should still check idiom, factual equivalence across language versions, and whether the two viewpoints are genuinely balanced rather than merely oppositional before training claims. This artifact has structural integrity evidence, not evidence of matching quality.
