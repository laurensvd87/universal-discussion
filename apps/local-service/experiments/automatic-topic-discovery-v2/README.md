# General named-subject policy candidate

This is a new development candidate. The frozen v1 source/policy/results are
unchanged. It requires two distinct material inputs with complete E5 cohesion,
deduplicates copies/near duplicates and keeps the same context, ambiguity and
work bounds. It reports the actual publisher count, including one.

Publisher diversity is useful corroboration; it is not required for a shared
subject. Several genuinely different product pages on one repair site may share
a product-family subject. This does not establish event equality, independent
reporting or factual truth. Repeated boilerplate cannot become a useful subject
name merely because the publisher check is relaxed: instructional/question
prefixes are excluded, preserving captured-title witness offsets.

The change follows the general-web screen and its extraction repair. Compare it
against unchanged v1 on all retained available pages, report naming/coverage and
remaining language/model distinctions, then validate on additional data. It is
not approved live, not a database migration and not a Wikipedia/entity dependency.
