# Author-selected context for general websites

Unregistered component for the complete future hierarchy18 profile. Importing its
repository has no effects. No migration, startup, UI or live installation is
implied. Schema1–17 and existing canonical topic/discussion/contribution IDs are
unchanged. Wikipedia/provider identity is not used.

`named_read_editor` returns a precise page caption as soon as a learned Source is
postable, even without a semantic preparation or shared subject. When current
protected membership supports a named subject, it returns that subject instead.
This read uses MVCC and performs no model request, discovery or queue write.
The editor must freeze the returned scope when typing/research begins; this
component does not yet connect that browser behavior.

`named_append_root` keeps the original canonical destination. It runs private
prepare, protects and validates the selected context, inserts its author-owned
caption, and completes the canonical watermark/receipt within one statement and
one physical transaction. The new application capability is execute-only.
Actor gate → operation receipt → Source → canonical discussion/topic/contribution
remains the existing order. Derived membership/head checks follow those locks.
The installed matcher can be locked there because owner activation never locks
the Source or canonical discussion; broad activation/ingestion coverage remains
necessary before live integration.

A draft binds Source material digest, stable subject ID and exact caption, not
evidence revision, Source write version, operation ID or current preferred leaf.
Thus identical-material renewals, additional supporting pages and a more specific
preferred subject do not retarget it. A page draft may finish with its original
page caption after a shared subject appears. Real material changes, erased
membership or a forged caption conflict and roll back all new canonical rows,
receipts and revisions. The UI must retain such a draft for review.

Exact replay checks both the original canonical command receipt and a separate
scope digest. An old schema17 command cannot be retrospectively relabelled by
replaying it through this port. A replay returns its historical revision even
after unrelated writes, and still succeeds after Source withdrawal.

Only the expressly posted scope ID/caption becomes author-owned. Public root
reads expose neither Source material digest nor private prototype. Source forget
can erase every derived subject head/member/vector while existing author-owned
caption, human body and canonical destination remain. Withdrawing or hiding that
human root removes its authored caption. The separate receipt digest is used
only to compare an exact command retry, never to recover a discovered identity.
It is not indexed for matching or topic search.
