## Bounded observation

Before the original callback validation, emit a detached projection with a fixed
callback event enum, bounded ordinal, current literal operation stage/edge,
loadingExtension/extensionIdentityEstablished booleans and finite target type.
Target type is one of declared known CDP kinds or unknown-type/invalid, never a
raw unknown string. Record URL CLASS only: empty, exact-about-blank, owned-worker,
other-extension, chrome-internal, devtools, HTTP, HTTPS, other or invalid. At most
a bounded length bucket and attached/context/opener-field presence booleans may
be included. No URL, origin, target/context/opener ID, title, raw payload, path,
arguments, environment or arbitrary error text/hash. Non-target callback events
use only their fixed event kind and known scope booleans.

At most32 callback projections and one first-fault record are retained. Keep the
unchanged variant trace and eight prelude events separate under64KiB combined
logs/1MiB evidence. Use descriptor-checked primitive projection, finite enums and
no arbitrary JSON serialization. Emission/projector failure cannot permit native
continuation or suppress the original callback/action/rejection; fail closed.
Capture observation failure separately, invoke the same original callback/action
exactly once, forward its original failure if any, then fail closed for the
observation failure if needed. In particular, early logging throws must not skip
an HTTP denial or cleanup. Non-target observation must not call extra client
methods such as `.url()`. Check raw string bounds before parsing/classification;
oversized strings yield only finite invalid/length categories.

Preserve the first actual fatal's finite origin and allowed error class/code,
separately from cleanup failure. Recognize only the actual imported StartupFatal
or NativeCaptureError constructors with primitive own `.code` in fixed CODE enums;
unknown errors become unclassified-fatal. Never infer class from error.name or
retain message/stack. Record bounded coordinator counters at first fault and after
cleanup without clearing unresolved physical capacity. Wrapper logging must always
forward the same original action/error to the original fail path, including when
observation fails. Pure helpers must not manufacture native/semantic authority.
Reject proxy inputs before class/prototype examination; require a genuine native
Error and the actual imported prototype/class plus a primitive own data-code
descriptor, without custom hasInstance/getter hooks. These categories describe
an in-process error, not native attestation. Zero-hook guarantees concern only
the projector: unchanged original callbacks retain their original input handling.

The real child uses the observed variant, and its generic terminal catch emits
only the finite projected fatal. No whitelist, ignored event, discovery filter,
sandbox/TLS/network relaxation, new helper allowance, retry or second profile
rescue is authorized. If the old rejection fires again, a failed diagnostic with
actual finite categories is the intended informative outcome, not a pass.
