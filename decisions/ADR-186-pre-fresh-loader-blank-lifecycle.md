## Narrow quarantine before fresh document evidence

Create a new public-journey-v2 implementation from immutable v1, and a fresh
native-specificity-study-v6 namespace from the60 v5-owned files. Leave all
consumed v1-v5 sources, maps, outputs and profiles unchanged. The successor study
uses only the new journey implementation and truthful producer source binding.

Keep the original prepared-phase replay rule unchanged. In dispatched phase
only, permit an exact initial-blank lifecycle event to be counted as initial
replay when ALL of these hold: the existing descriptor, incarnation, frame,
loader syntax, finite nonnegative timestamp, bounded name, event cap and original
lease checks pass; the name belongs to the existing ten IGNORED_LIFECYCLE
literals; and no fresh-loader evidence has yet been accepted. Fresh-loader
evidence means any reply, commit, response or DOMContentLoaded fact, OR the
private fresh lifecycle candidate. These are direct private state checks, not
caller booleans, mask approximations or a resettable new flag.

The quarantined event contributes no fact, candidate, arrival order, readiness,
phase advancement or reading authority, and cannot reset the original deadline.
Count it only in the existing bounded initial-replay category counters; no new
schema field or raw event retention is needed. It is still charged exactly once
against the original4096 event cap. Unknown bounded names, commit and
DOMContentLoaded remain refused for blank loaders after dispatch. The exception
ends permanently when the first fresh-loader fact or candidate is accepted.
It cannot apply in resolved or retired phases, to a wrong frame/incarnation,
different loader, malformed input or an expired lease.

Blank-loader reply, commit and main response remain fatal. A blank lifecycle
after any fresh-loader fact/candidate remains fatal, including delayed initial
events. All seven fresh readiness facts, request links, real native-document
attestation, TLS/peer/rights checks and actual physical drain remain mandatory.
Do not move begin after awaiting Page.navigate, delay to hide ordering, remove
listeners, widen article event names or fabricate unavailable input.
