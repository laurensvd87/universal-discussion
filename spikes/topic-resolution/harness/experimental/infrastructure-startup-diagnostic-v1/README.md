# ADR198 owned startup diagnostic

Source readiness is reviewed (adr198-reviewed-startup/v1), not phase permission.
Import and no-argument execution are inert. The two
actual modes require separate Root decisions after complete source acceptance,
independent closure/pins and saved-evidence audit. No actual mode has been run
by implementing this component. No study successor or automatic retry follows.

The parent CLI accepts exactly:

```text
python supervise.py --prepare --source-paths-sha256 SHA --source-map-sha256 SHA
python supervise.py --run-startup --source-paths-sha256 SHA --freeze-sha256 SHA
```

Paths are fixed, never CLI inputs. The reviewed map is reviewed-sources.json;
metadata preparation owns a fresh output/prepare leaf and publishes freeze.json
and supervisor.json final/pending hardlink pairs. Preparation starts no Node,
Job or browser and explicitly reports nodeStarted:false/jobCreated:false.
READY/baseline/drain/empty-Job evidence is inapplicable to preparation.
The later startup mode consumes that independently FILE-pinned freeze and owns
fresh output/startup, temp and profile-01/profile-02/profile-03 directories on D.

Parent authentication pins source-paths FILE before parsing, then reviewed-map
or freeze FILE before following keys. Full CODE and115 maintained Playwright
files (13656167 bytes) authenticate before Node. The independently pinned
playwright-route-burst-dev-v1/freeze.json is one additional non-CODE metadata
file. Its original single final LF is removed only AFTER FILE authentication;
only its115 package hashes are used, never its other paths. The literal CODE
list includes the complete inert StartupFatal dependency graph. Evaluating those
modules grants no permission to invoke dormant model/crawler/artifact functions.
Actual closure counts remain subject to independent inventory review.
The authenticated115 package FILE keys determine the entire permitted directory
and child-name closure (at most921 directories, depth8). Enumeration stops at
the129th entry before append/sort; unknown names, including empty directories,
are rejected before descent. The original authentication fence surrounds every
visit and iterator step; the exact115-file/13656167-byte identity still applies.

The parent authenticates whole immutable v13 and low-level helper bytes before
evaluating their inert modules. Only generic enumeration/memory/assignment/
resource/native-path/pipe/metadata-walk helpers are used. No NativeSession,
old main, phase publisher, ProofService or hardcoded study_usage call is used.
No module globals/defaults are patched. New publication accepts only fixed
owned paths with exclusive creation, native identity sampling and retained
final/pending hardlink pairs. Samples are non-atomic, not a kernel path sandbox.

Startup owns one DETACHED Node, HELD on its original assignment pipe. The
launch-owned process handle is retained before inspection/assignment. Job limits
0x2208/128/1536MiB are read back. The assigned original Node image/creation/Job
identity and complete resource sample precede HANDSHAKE. Before handshake the
child imports only builtins and authenticated v13 pipe-channel. READY/baseline
ACK precedes the child's full source/package verification and client import.

One exact monotonic request/response chain drives source proofs, READY,
PROFILE_BEGIN, PROFILE_DRAIN/FAILED_PROFILE_DRAIN, STARTUP_FAULT and
COMPLETE/FAILED_COMPLETE. Logical state advances only after original ACK write
and flush physically settle. One original exchange remains owned through
observation failure; no overlapping or retransmitted fault report is allowed.
The pipe guard is terminal-safe from creation; normal work admission separately
retains sticky first failure. Transport failure remains permanently terminal.
Fixed milestone-NN.prepared.json and milestone-NN.committed.json pairs retain
the exact bounded request/ACK metadata for READY, each begin/drain, first fault
and completion. A prepared record is not physical ACK evidence. Committed
records are published only after the original ACK write settles; the supervisor
joins their FILE hashes, the exact source/list/freeze/Node/bootstrap/baseline
bindings, result/fault FILE hashes and committed head/counters. Filesystem proof
traffic retains a compact chain checkpoint, not independent raw-frame replay.

Each of at most three profiles seals the actual about:blank anchor through its
own CDP session, installs denials and discovery listeners, then performs exact
unfiltered discovery, pre-load and final census using the actual ADR197 policy.
Both context/browser closes are attempted once where handles exist. Listeners
remain live through independent parent baseline drain and ACK. First fault
stops subsequent profiles. No extension stage/load, public navigation, worker
evaluation, native read, model assets, inference, provider or database exists.

The exact first original error stays private. Only the actual197 exact-error
reader can associate its finite witness. Native error code projection requires
trusted native Error/prototype identity; forged/proxied error records remain
generic. The bounded early STARTUP_FAULT evidence pair is saved before potentially
hanging cleanup; evidence identity is sequence/digest, not Error serialization.
Unsafe native returns are quarantined without hooks, with a permanently charged
unknown physical obligation. Wrapper rejection never proves original settlement.

Success requires both closes, original promise/callback settlement, exact original
Node/console baseline between profiles, normal Node exit, reader EOF without
extra/partial frames, joined writers/readers, empty Job, closed handles and final
source/resource checks. Emergency termination always prevents success. An
already-exited Node with surviving/unknown Job members still requires owned Job
termination. Buffered streams are not closed while original threads own them.

Original bounds remain360s active/420s total/60s Job CPU; metadata mode labels
its separate parent CPU. Bootstrap30s, READY15s, profiles45s, baseline drains15s.
Non-collecting held absolute fences apply before/after complete Job queries,
native proofs and physical writes. Thirteen old study roots plus this root share
8GiB/344064 entries, evidence32MiB, logs1MiB; current profile/temp512MiB/8192 entries.
Host physical/commit1GiB, C2GiB/D4GiB,128 processes and1536MiB remain unchanged.
The197 fixed320-byte reservation stays inside32KiB logical retained accounting.
The fixed installed Chrome path is a trusted host-binary assumption. Repository
source/package authentication does not attest that browser binary's bytes.
