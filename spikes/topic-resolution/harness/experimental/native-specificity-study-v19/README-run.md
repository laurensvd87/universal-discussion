# Default-inert phase composition

ADR200's fresh v14 source preserves the complete phase/semantic/admission
contract. Its actual ADR197 policy FILE hash is bound in the29-source recipe;
the added nullable failure witness is observation only, never phase authority.
All consumed studies and startup diagnostics remain immutable. No new phase is
authorized by this source or by a future readiness marker.

`createSpecificityPhaseRunner` composes the reviewed contracts. Importing or
directly executing this module performs no study. Actual IO/native/owned-Job
capability wiring, source freeze/preparation and explicit commands are unfinished.
Injected capabilities are trusted seams, not evidence of their own authority.

The input binds canonical manifest and separate panel/manifest pins, validated
profile set and recipe pin, unchanged reused root candidate and reuse-receipt
hash, phase (`train-cal` or `test`), selection (`null` for TRAIN/CAL), original
Node identity hash and absolute phase deadline. `capabilities` is exactly:

`guard, now, captureBatch, releaseBatch, assertCaptureHealthy, requestBatchDrain,
verifyBatchDrain, requestFinalDrain, createEncoder, recheckAssetsAndSources,
authorizeTest, enterModelStage`.

After the final cohort ACK has entered encoding, encoder closure and its
endchecks precede `enterModelStage({phase,stage,captureHash,encodingHash})`.
The trusted actual owner must obtain the external guardian's ACK before returning
exactly `true`. Stages are `fitting` (TRAIN/CAL) or `assessment` (TEST), followed by
`checks`. No fitting/scoring or final checks dispatch before its ACK. The local
180/60-second stage lease begins before transition publication, includes its wait,
and is not renewed by semantic consumption. Parent and Node clocks stay separate.

`captureBatch({batch,onRow})` must invoke the reviewed real collector with its
checked owned stage/browser/DNS/policy capabilities. Its returned ORIGINAL
summary identity is retained through actual guardian drain authentication.
`prepareBatchDrain` first supplies the cohort's private current-four-row and
bounded summary hashes without advancing anything. `requestBatchDrain` receives
those hashes alongside the ORIGINAL capture summary and obtains actual immutable
guardian bytes; synchronous
`verifyBatchDrain` independently checks them against the cohort's requested
case/capture/summary/manifest/Node bindings recomputed by `finishBatch`.
Only then is `releaseBatch(summary)` called.
No next batch, final drain, encoder or selection can precede those gates.

Admission independently validates full bracketed rights and the unchanged native
input preparation. `sourceVersion` is the actual `observationNonce`. Cohort
evidence retains prepared metadata plus rights, not copied raw text; revalidation
binds that same closed-capture evidence and is not a later browser reread.
All96/72 rows and24/18 actual batch ACKs precede final-cohort ACK and sequential
E5. Encoder closure and source/asset checks precede semantic consumption.

TRAIN construction retains every48 availability row and original annotations,
with body/title bit hashes held independently by the cohort. No references stops
before fitting. Otherwise ALL48 CAL rows go through the unchanged fitter once,
including root-abstained available inputs. `takeSelection()` is available once
after successful phase completion. It returns bounded selected TRAIN-reference
codec text/bit identity, construction and actual CAL audit fields; no raw pair,
CAL/TEST query vector or duplicate lossy artifact-number arrays are retained.
The phase report also retains an ordered96/72-row metadata-only input ledger:
case/group/split/global and native ordinal/batch, prepared input identity, field
bindings and native/rights/vector-bit hashes. Unavailable cases retain their
identity and reason. Selection binds its TRAIN/CAL ledger hash. This preserves
association evidence after transient queries are dropped, without pretending to
reconstruct the fitter's omitted features or270-cut ranking from their hashes.
The selection is still pending independent actual saved-byte audit. No TEST
permission is implied by selection creation or its self-hash.

TEST's `authorizeTest` must authenticate independent saved selected codec/audit/
TRAIN-CAL supervisor bytes, normal closure and source/asset endchecks before any
TEST batch opens. Future trusted IO owns that verification; a matching supplied
selection/audit hash is not sufficient. TEST decodes the pinned selected codec,
uses the unchanged root scorer and root/detail adapter, and reports work honestly:
baseline root scoring plus the composition's OWN root scoring are both counted.

`assessSpecificityTest` keeps a70-supported-label assessment subreport beside
full72 availability/accepted denominators and both unknown prediction statuses.
The unknown rows never receive fabricated gold or semantic-rejection credit.
Assigned unknown fails the fixed gate. Prefix descendants remain unchecked, not
correctness credit. Root-only is descriptive, never a TEST-selected alternative.
Numeric scoring timings are not end-to-end UI or embedding latency measurements.
They include phase-guard overhead, and both scorer call counts are explicit.

Every trusted operation is fenced before/after dispatch/settlement; original safe
Promises stay charged until actual settlement. Unsafe Promise originals are
refused without hooks and remain the external owner's physical/rejection tracking
responsibility. One sticky failure prevents rerun/publication. The outer guardian
still enforces physical cancellation, resource bounds and actual terminal cleanup.
No canonical writes, provider actions, crawler actions or activation follow.
