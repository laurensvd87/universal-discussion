# Composed owned Node-only bootstrap DEV

ADR158 source-only four-file composition. Default entry points are inert; source
review, one metadata preparation, actual freeze audit and one owned run remain
separate root permissions. No browser, content, model, provider or database action.
This is not a replay, cause attribution or semantic-quality result for ADR155.

Both programs inventory the same ordered13 literal CODE/metadata keys. No package
walk, JSON-supplied path traversal or old201 inventory. ADR153 Win32 helper and
ADR155 pure validator bytes are authenticated against fixed freeze FILE and fixed
source pins before private exact-byte execution under original `__file__` globals.
ADR157 census bytes are bound by the new validated13-key freeze. No old main,
source inventory, old output function, count-only drain or pycache is invoked.

Incremental policy validates actual supplied confirmed/gone rows immediately.
Original Node identity is actual opened-handle PID/exact creation FILETIME/path
hash. Optional fixed console identity is remembered from its first confirmation,
even if it exits before READY. Unknown/replacement/late members are fatal. This
is a trusted-host/path assumption, not signature/binary/ancestry/native authority.
Historical identities never fabricate a current row; final membership comes from
the growing census. Node absence requires actual exit0 plus exact completion.

READY pending baseline, ACK sealed baseline and completion bind ordered compact
UTF8 JSON hashes of13sources, freeze FILE, actual original PID/creation and exact
one READY/ACK pair. Markers publish exclusively via pending files and atomic links.
The child echoes supplied creation identity, not independent native observation.
Completion is consumed even if published during census/exit. Final normal drain
continues identity checks. Primary finite census/policy failure and separate cleanup
code remain visible; emergency own-Job/original-child termination is always failure.

Fixed installed Node, hidden direct launch, heap256MiB/Job1536MiB; host1GiB,
C768MiB/D512MiB reserves; owned D TEMP only. READY15s/ACK5s/child25s from Popen,
guardian30s active40s wall/cleanup5s. Census2s cooperative/8unionPIDs/9rounds/32rows.
Active time starts before the initial inventory; deadline checks precede native
initialization and direct Popen, so an already-expired budget cannot launch Node.
If Popen itself crosses the deadline, the returned child is retained and assigned
to the own Job before deadline rejection; no handshake follows that rejection.
Evidence64KiB/file, logs64KiB combined,total256KiB/256entries. Native APIs cannot be
forcibly interrupted by cooperative deadlines. Failed evidence is retained, never
deleted or retried. Passing would grant no browser or application activation.

Tests use invented source buffers, handles, metadata, policy and clocks only. No
preparation, native DLL/child, actual artifacts, old output or executable bytes.
