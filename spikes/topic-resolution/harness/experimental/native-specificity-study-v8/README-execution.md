# Source authentication and parent drain wire

ADR188 is a source-only successor to the closed failed ADR187 TRAIN/CAL attempt.
Root and Trust accept the complete source; Versions accepts its full closure.
The reviewed marker `adr188-reviewed-execution/v1` cannot replace final source pins or a
separately recorded actual phase decision. Preparation remains a separate gate.
Neither source flags nor a matching hash grant phase authority. Original frozen
v1/v2/v3/v4/v5/v6/v7 source and output remain intact. Actual
collection, model evaluation and TEST require their own decisions and evidence.
Importing `execute.mjs` starts no IO, browser, process or model. The sole early
private import is the default-inert, builtin-only original-pipe adapter: the
native parent authenticates the complete CODE/package before starting Node, and
the adapter reads the actual assignment header before other private imports.
The child's baseline and full source gates still precede study actions.

`authenticateSpecificitySourceList(bytes, externalFileHash)` authenticates the
CODE FILE before parsing its literal `SOURCE_PATHS` array. The list must be
sorted, unique, case-distinct and traversal-free. A self-hash supplied with an
untrusted file is not the external pin. `authenticateSpecificityReviewedMap`
similarly authenticates a fixed reviewed-source-map FILE before JSON parsing
and requires exactly the literal CODE keys. `authenticateSpecificityCode` follows
only those authenticated literal paths, never JSON-selected paths. Reads are
bounded4MiB/file,32MiB total and fenced after physical original settlement.
The supplied trusted reader still owns native path/handle checks and cleanup.

`authenticateSpecificityFreeze` checks the separately pinned FILE before parsing,
its canonical JSON/self-identity, exact CODE plus115 maintained-package entries,
package version size baseline, ordered24/18 batch IDs and all42 exact seven-file
stage hash maps. Those stage hashes are derived purely from the reviewed stage
constructor during later approved preparation, before any real stage is created.
The frozen recipe includes independent catalog/context/manifest/panel/producer/
encoder/asset identities. Prospective preparation uses the fixed names
`output/prepare-r3/node-owned/freeze.json` and `reviewed-sources-r3.json` inside
the fresh v8 namespace; no old maps or outputs are present or adopted there.
All v1/v2/v3/v4/v5/v6/v7 maps and outputs remain unchanged at their original paths and count
toward the shared aggregate resource ceilings. No actual v8 freeze has been prepared.

Response transport continuation is separate from independent response admission:
it cannot grant response/native-read authority. The nullable timer witness names
only the exact first coordinator timer error, not an inferred last-RPC cause.
These capture-order/diagnostic changes grant no actual compatibility or quality claim.
The typed CDP adapter validates exact `{frame,type:'Navigation'}` before projecting
one copied `{frame}` to unchanged owner/journey readiness checks. The discriminator
is not collection authority; missing/extra/unsafe envelopes and BFCache are refused.

`createSpecificityDrainWire` takes independent phase/freeze/manifest/original Node/
source-map bindings, the phase's ordered batch IDs and trusted guard/clock/
publish/read/sleep capabilities. No default capability performs actual work.
It publishes one bounded request and accepts its exact parent ACK bytes;
missing ACK waits at most15seconds without retransmission. The physical original
Promise remains charged after abandonment until actual settlement. Unsafe
Promise hooks are refused without execution and remain the external owner's
physical/rejection-tracking obligation. Errors are sticky.

Batch-start ACK precedes setup/DNS. Batch-drain ACK binds the cohort's prepared
private metadata hash and original summary hash; `verifyBatchDrain` checks the
later independently recomputed hashes and actual privately held ACK bytes.
It never treats a caller boolean or supplied matching self-hash as parent proof.
The24/18 ACK byte hashes form the guardian's ordered chain. The final-cohort ACK
binds that complete chain and cohort hash before model initialization. Mapping
the accepted parent request back to the cohort's smaller request keeps both
identities explicit. Node request/arrival times are compared only in Node's
clock domain; Python's `observedAt` is not compared to them. Its sole finite
nonnegative numeric token may use CPython's whole-float/exponent JSON spelling;
all other ACK bytes must match the exact closed DTO rendering. The original
parent bytes, not a V8 reserialization, supply the receipt hash. Duplicate keys,
extra fields or surrounding whitespace are still refused.

Fitting/assessment then checks require explicit parent stage ACKs. Stage messages
bind the same final capture and encoding identities; control ACKs never modify
the guardian drain chain. The actual driver now connects this wire to the
reviewed IO/native parent; isolated tests are not actual native evidence. Canonical
and crawler integrations, actual quality/latency tests and live activation remain
unfinished. Tests use only invented CODE, metadata, clocks, IO and ACK bytes.

`createSpecificityFsProofWire` adds the default-inert Node side of the owned-pipe
native-proof seam. It binds phase/external source FILE identity, sequence, nonce,
edge and fixed path key plus prior chain. Each original exchange stays charged
until physical settlement. Frames are bounded16KiB BEFORE accumulation/UTF8/JSON;
reject multiple/truncated frames, wrong response joins, reparse attributes and
invalid native identities. One exchange,65536 sequence values and64MiB BOTH-way
wire bytes are hard limits. The original channel owner must additionally enforce
8 queued frames/128KiB and reject unsolicited/extra/EOF frames immediately even
while no exchange is awaiting a read; this injected helper cannot prove that from
a callback. No pipe is opened here. The real parent alone maps literal path keys
and performs native ancestor/opened-object checks. Matching supplied DTOs cannot
establish that origin. Native and Node identity domains remain separate, and
sampled proofs are not a kernel-atomic path sandbox. Retain only counters/max-frame
and compact request/response hash chain, not all raw frames or replayable evidence.
`checkpoint()` is available only while healthy and physically idle. It names the
last accepted sequence/head BEFORE a milestone's own publication, not the chain
after that publication. The actual parent must validate its known-head match at
first milestone observation, retain at most64 recent heads, cache only the three
ordered milestone bindings and fail closed on eviction. Only a successful final
supervisor after actual exit/pipe settlement may name the terminal chain.

Only four fixed `control:` aliases and four TEST-only `audit:` aliases are
recognized. The parent restricts reviewed sources to PREPARE, the prepared freeze
to TRAIN/TEST and audit files to TEST. Python does not reserialize Node numeric
JSON to claim JavaScript byte or semantic identity: external FILE pins, strict
decoded schemas and the child's unchanged JavaScript digest/codec remain distinct.
