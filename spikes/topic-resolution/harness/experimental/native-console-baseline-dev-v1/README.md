# Exact owned Node/optional console baseline DEV

Source-only, default inert. Preparation and one actual run require separate root
and independent review. No browser, content, model, application or database action.
The builtins-only child is not byte-identical ADR151 initialization and does not
guarantee reproduction of that failure.

The guardian authenticates the immutable ADR153 freeze and helper bytes before
executing helper definitions in a private module with the original `__file__`.
No old main, output helpers, count-only drain, global redirection or bytecode cache
is used. Inventory is the authenticated old201 fixed CODE/metadata keys plus these
five files, ADR155 and the fixed ADR153 freeze:208 keys. JSON never supplies paths.
Python executes the verified bytes. Node uses the ordinary ESM loader after its
fixed source pin and checks the source inventory again; this is not an atomic
OS code-execution attestation or sandbox.

The fixed installed Node image and optionally one exact system console image are
a trusted-host/path assumption, not a signature/binary/ancestry or native authority
attestation. PID and creation FILETIME strings remain exact. First console identity
is retained even if it exits before READY; replacements and late consoles fail.
Inspected confirmed identities absent from a later fresh census are historical,
not evidence of live membership. Gone rows never establish a live member.

READY declares baseline pending. A fresh same-Job census seals ACK, binding READY
bytes,208-map hash, freeze FILE hash and original handle identity. Completion echoes
one exact READY/ACK pair. All JSON uses ordered keys, UTF8 and compact separators.
Publication is exclusive pending-file plus atomic hardlink; partial final markers
are never visible. The child echoes guardian-supplied creation identity; it does
not independently observe Win32 creation time.

Actual exit0 plus exact completion is required before Node absence is accepted.
Normal final drain continues full identity checks, including late additions; an
eventually empty count alone cannot pass. Retained diagnostics deduplicate exact
rows (32 distinct transitions), while every healthy sample is still checked.
Emergency termination is failure, scoped only to the own Job/exact child.

Limits:256MiB Node heap,1536MiB Job RSS/private; host1GiB/C768MiB/D512MiB reserve;
READY15s/ACK5s/child25s/guardian30s active40s wall/cleanup5s/census2s cooperative.
Evidence64KiB/file, logs64KiB combined,total256KiB/256entries. Native calls remain
cooperatively bounded. Failed output is retained, never recursively removed.

Pure tests use invented source bytes, identities and injected census callbacks.
No preparation, native child or DLL execution is part of those tests.
