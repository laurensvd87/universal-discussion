# ADR148 browser root-transfer collector — source only

New browser-only reobservation of the exact sealed32 ADR143 identities/order,
eight fixed batches of four. Not an untouched cohort, ADR145 resumption, old
packet rescue, runtime integration, native attestation or activation. Every
older source/result/artifact remains unchanged. No model/encoding/scoring exists
in this collector. Root separately authorizes receipt/freeze and each real phase.

`supervise.py --browser-batch N` is explicit; defaults are inert. It assigns its
own Win32 Job BEFORE the exact stdin handshake permits public policy work or the
client import. Existing installed `playwright-core`1.64.1 is reused read-only
from `experimental/playwright-dev-v1`; no installation/browser download happens.
Installed Chrome uses a package-owned ephemeral profile in fresh D:TEMP. A fresh
context per article has no previous cookies/storage/HTTP credentials. Routes and
socket denial precede its sole page. No owner profile, app, pairing or provider
is used. Only Playwright cleans its generated profile; no custom deletion exists.

One current main-frame GET/HEAD Document is reserved synchronously. Redirects,
later navigation, non-Documents, popups, Service Workers, sockets and downloads
are denied. Headers strip declared credentials; a fresh context also prevents
prior article cookies from being appended by the browser. Fresh URL-specific
robots/TDM checks use the frozen final-v2 PURE policy function, NOT any old output
or static eligibility. At most8 policy requests/5s each and complete pacing fit
60s. One matching DCL+2s reader snapshot fits a20s article lease.
The goto(waitUntil:commit) await alone may use the remaining SAME20s lease;
other RPCs retain min(10s,remaining lease). Playwright's goto timeout is disabled
so only the private owned article timer can report article-timeout. It marks the
article stopping/closes its gate before cancellation; global failures win. No
timer reset, second navigation or20+10s extension is permitted.
Existing title200/body4096 UTF16-unit bounds remain; no truncation/new field-byte caps,
pruning, Wikipedia lead, replacement, retry or title rescue.

The response must reference the exact admitted Playwright Request object, have
the exact URL,2xx HTML, a public non-null peer, ordinary verified TLS, bounded
header rights and DOM directives. Independent CDP frame/loader/world/current
document checks fence every awaited boundary and synchronous paired retention.
The full `playwright-owned-document/v1` witness retains bounded response/DOM
projections and recomputable hashes, never raw headers, addresses or PW objects.
`networkRequestIdCorrelated:false`/`nativeAttestation:false` are explicit.

Document identity derives from frozen observation/case/batch/actual frame/loader/
navigation IDs. Source version is `freezeHash|browser-only|batch`. The full input
envelope binds both text hashes, exact profile/builder/extractor, rights hashes
and the full witness BEFORE any reduced old-scorer DTO is projected. Packet
validation crosschecks collected metadata outcomes, not only self-consistent
packet fields. Only exclusive `input.packet.json` may contain checked title/body,
max128KiB/four rows; ordinary results contain bounded projections/hashes/lengths.
Packets persist pending root-verified downstream encoding/source review; no
automatic deletion or license assertion follows from public visibility.

Exact current `Request.failure().errorText` matching one of seven declared
`net::ERR_*` strings produces unavailable. This is a pinned human-readable API
field allowlist, NOT portable typed Playwright enums. No trimming, substring or
thrown Error.message parsing. Null/malformed/unknown/TLS/cert/blocked/aborted
active failures are fatal. Already-known blocked requests and retired/stopping
articles alone are ignored. An allowed current failure immediately sets private
refusal; already-observed refusal may classify rejected goto, never arbitrary
exceptions. Global failure/abort/resource guards always win. Unknown protocol or
integrity failure closes the entire namespace: no later batch/prefix scoring.

`manifest.js` exposes strict packet/envelope validators and reduced-witness
projection (no vectors/classifier). `producer-profiles.js` builds ONLY the new
browser profile. Construction includes six runtime files, frozen policy/reader
dependencies and the entire bounded sorted package tree, excluding receipt/
freeze/reuse helper/fitter protocol to avoid cycles. Matcher-owned reuse helper
binds precisely the unchanged selected artifacts/.75-.25 input and successful old
fit proof. The ORIGINAL static profile is carried verbatim only as an explicitly
unexercised compile dependency; no static result/acceptance is asserted.

Source freeze pins all actual own/transitive sources, package/lock, exact candidate
and seal, old-fit proof and the new reuse receipt separately. All paths are fixed
in code, never followed from JSON. Same bytes are hashed/parsed, then rechecked
before publication. Complete installed package bounds remain128files/16MiB and
4MiB/file; total source keys<=256. Prior batches require matching complete result,
successful no-emergency supervisor and packet BYTE hash only, no packet parsing.

1536MiB Job commit/RSS/private, continuous host1GiB/C768MiB/D512MiB reserves.

Normal success requires an empty Job without emergency termination. Failure
