## Fixed schedule and unchanged guards

Defaults are inert. Only `python supervise.py --static-batch N` and
`python supervise.py --browser-batch N` exist, literal N=1..8. No automatic batch
invocation, adaptive split, retry, redirect rescue, replacement, old input splice,
partial evaluation or automatic deletion. All8 static batches must complete before
browser01; every later batch verifies the earlier successful result, packet and
cleaned-up supervisor bytes. Fatal failure prevents every subsequent batch.

Each batch has exactly four predetermined cases; all32 remain each producer's
denominator. Static <=360s/batch (<=2880s overall), <=64 policy+32 page requests,
unchanged15s request limits. Browser <=180s/batch, <=60s complete policy phase
including pacing, four absolute20s article leases (matching DCL+2s, latest DCL18s),
<=35s child startup/overhead/checks/close and <=5s own Job drain. No guard is raised.

Keep DNS/TLS, header/framing, MIME/UTF8, byte/decompression/ratio, robots/TDM,
noindex, fixed NL snapshot repair, current static extractor (NO metadata pruning
or Wikipedia lead) and exact current reader. Batch-local policy cache evaluates
robots/TDM for each URL and shares origin request pacing; no cross-batch freshness.
Static transport/representation/rights uncertainty blocks BOTH producers. Only
insufficient text after fully successful static rights checks can allow browser.

Browser scope remains restricted-single-document-dom-reader/v1,
ordinaryDynamicBrowserProducerValidated:false. Only GET/HEAD Document requests
to the exact current URL in the known main frame are admitted once per article.
All external scripts/styles/XHR/Fetch/Other/media/images/fonts/workers/sockets

## Finite external failures and diagnostics

Only direct non-proxy native PublicFetchError instances, own DATA code/cause
fields and the exact ADR145 table can become unavailable. Request-local timeout,
valid non200 HTTP (existing policy404/410 absence unchanged), direct typed
response-aborted/body-too-large/headers-too-large/compression-ratio/content-type,
two DNS cause codes, seven socket cause codes, and explicit unsupported/zlib/
output/UTF8 cases are allowed. Full literal sets are in protocol.json and tests.
A generic socket code does not prove TLS negotiation occurred. Concrete TLS,
certificate, unsafe DNS/address/pinning, malformed headers/framing, invalid
URL/options, unknown pair/class/getter/proxy, programming/source/protocol/
resource failures remain fatal. Global deadline and abort checks always win.

Only an exact current admitted main Document/session/frame/network ID may turn
one of seven exact Chrome error enums into browser transport-unavailable.
No error substring matching. Explicit own blocked/teardown IDs cannot contaminate
a new observation; unrelated or unknown failures remain fatal. No new input is
retained for a refusal. Valid noisy/generic bounded input remains evaluable;
wrong semantic roots count, with no post-score manual quality exclusion.

Every post-DCL awaited boundary (frame/world/timed wait/snapshot/final frame)
checks the private captured article incarnation, global guard, fatal/refusal and
non-stopping/non-finishing state. One final check immediately precedes a
synchronous retain+collected publication block with no intervening await. An
allowed late own failure yields unavailable with ZERO retained input. Any coarse
Fetch.responseErrorReason is fatal BEFORE HTTP refusal handling or deliberate
blocked-ID marking; it cannot hide a subsequent TLS/unknown failure.

Diagnostics are fixed phase/batch/case/origin/resource-stage, disposition, family,
allowlisted code/cause and optional valid status. Unknown codes become `other`
while remaining fatal. Shared policy work has caseOrdinal:null and the actual
origin ordinal, never a guessed pending article. At most32 events/16KiB.
Observer sync/native-Promise failure is consumed without changing disposition or
printing errors. No message, stack, URL, headers, text, IP, credentials or request
IDs enter these diagnostic events. A fatal shared-policy error leaves unattempted
article rows unattempted; the batch itself is fatal.
